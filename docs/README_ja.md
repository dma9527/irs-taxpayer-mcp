## 12月31日までに数字を確かめる

今年Roth変換をすべきか。0%税率の範囲で含み益のある投資を売却できるか。401(k)の拠出枠を使い切るべきか。これらの判断には期限があり、実際のお金がかかる場面では、チャットボットの大まかな推定では足りません。

`irs-taxpayer-mcp` は、米国の個人納税者向けの決定論的な税額エンジンです（TY2024からTY2026）。IRSの年度別テーブルから計算し、計算過程を示し、未対応のケースでは推測を拒否します。

- 🔒 **数字を手元のマシンに留められます。** 直接CLIはローカルで計算し、MCPを起動せず、モデルを呼び出さず、税務データをどこにも送信しません。
- 🎯 **生成ではなく決定論的。** 同じ入力には常に同じ結果が出ます。計算を言語モデルが行うことはありません。
- 🛑 **未対応ならエラーを返します。** 未対応の年度、州、不足している必須情報に対しては、大まかな見積もりではなくエラーを返します。
- 🤖 **AIアシスタントとも使えます。** Claude、Kiro、CursorなどのMCPクライアント向けに45のMCPツールを提供します。

## 🚀 30秒で試す

```bash
npm install --global irs-taxpayer-mcp
irs-taxpayer-mcp intake --output taxpayer-facts.json   # ローカルの対話式質問票
irs-taxpayer-mcp plan --facts taxpayer-facts.json
```

合成データの世帯での結果例です（TY2026、夫婦合算申告、W-2給与 $185,000、長期キャピタルゲイン $12,000、子ども2人）。コマンドの出力は英語です。

```text
# Local Tax Plan for TY2026

Adjusted gross income: $197,000
Taxable income: $164,800
Federal tax after refundable credits: $20,440
Employee FICA: $14,122
Total modeled tax: $34,562
Take-home income: $162,438
```

`--json` を付けると、前提条件、公式な出典、計算過程、`privacy.modelInvoked: false` を含む構造化出力が得られます。

## 💡 判断に役立つ場面

| 質問 | ツール | 例（合成データ、TY2026） |
| ---- | ------ | ------------------------ |
| 今年のRoth変換にいくらかかるか | `simulate_tax_scenario` | 夫婦合算申告で所得 $150,000 の場合、$30,000 の変換で連邦税が $6,600 増え、一律22%になります |
| 0%税率で含み益を売却できるか | `optimize_capital_gains` | 0%区分の残り枠を示し、損失がすでに非課税の利益を相殺するだけの場合は警告します |
| 標準控除と項目別控除のどちらか | `standard_vs_itemized` | 選んだ年度のSALT上限、寄付の下限、項目別控除を使わない人の寄付控除を適用します |
| フリーランスは四半期ごとにいくら払うか | `estimate_quarterly_tax` | Form 1040-ESの金額とsafe harborの案内 |
| 給与の源泉徴収は足りているか | `analyze_paycheck` | 税額控除を含めて年間税額を予測し、W-4の見直しを提案します |
| 州を移ると節税になるか | `analyze_relocation_taxes` | 年度を指定して州税を比較します。検証済みの設定がない州はエラーになります |
| 2つの税年度で何が変わったか | `what_changed_between_tax_years` | TY2025とTY2026のルール変更を一次資料の出典付きで示します |

## 🔒 プライバシー最優先

**決定論的エンジンはネットワーク要求を行わず、税務データを保存しません。** 直接の `intake`、`validate`、`plan` コマンドはMCPを起動せず、モデルも呼び出しません。

- 直接モードのプランには `privacy.modelInvoked: false` が含まれます。MCP経由では `true` になります。クラウド上のクライアントが情報を見ている可能性があるためです。
- MCPクライアントに入力した税務情報は、そのクライアントのモデル提供者によって処理される場合があります。完全にローカルで処理したい場合は、CLIを使ってください。
- 新しいfactsファイルは、macOSとLinuxではパーミッション `0600` で作成されます。インポートは1 MiBまでで、シンボリックリンクと未知のフィールドを拒否し、氏名、SSN、住所、雇用主ID、口座番号は受け付けません。

## ⚡ MCPクイックスタート

MCPクライアントの設定に次を追加します。

```json
{
  "mcpServers": {
    "irs-taxpayer": {
      "command": "npx",
      "args": ["-y", "irs-taxpayer-mcp"]
    }
  }
}
```

保存後にアプリを再起動してください。MCPクライアントに入力した情報は、そのモデル提供者によって処理される場合があります。実際の税務情報を入力するかどうかは、その点を踏まえて判断してください。

## 📊 対応税年度

- **TY2024**：IRS Rev. Proc. 2023-34
- **TY2025**：One Big Beautiful Bill Act（標準控除 $15,750/$31,500、CTC $2,200、SALT $40K）
- **TY2026**：IRS Rev. Proc. 2025-32とSSAの2026年拠出・給付基準額（標準控除 $16,100/$32,200/$24,150、CTC $2,200で最大 $1,700 が還付対象、SALT上限 $40,400、AMT基礎控除は $500,000/$1,000,000 を超える部分で50%逓減）

## 対応範囲と限界

- 決定論的な税額見積もり・計画エンジンであり、申告ソフトウェアではありません。申告書の作成、署名、送信は行いません。
- 連邦税の見積もりは、各ツールが明示的にモデル化した入力のみが対象です。Form 1040のすべての行、スケジュール、選択を実装しているわけではありません。
- 州税の参照データは50州とDCを対象としますが、数値見積もりには年度ごとの検証済み設定が必要です。それ以外の経路はエラーを返します。
- 市、郡、学区の所得税は含まれません。
- 還付の予測は、入力内容とモデル化された還付可能な税額控除のみに基づきます。IRSの還付判定ではありません。

対応範囲の全体は[英語版README](../README.md)を参照してください。

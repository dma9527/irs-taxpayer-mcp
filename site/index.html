Know the number before December 31.

Should you convert to Roth this year? Sell winners in the 0% bracket? Top up the 401(k)? Get the exact figure from IRS tables, with the work shown, and keep your finances out of a chatbot.

Two ways in, and the difference matters

Both run the same engine. They differ in who else sees your numbers.

Direct command line

Private by construction

  • Starts no MCP connection and calls no model.
  • Makes no tax-data network request and sends no telemetry.
  • Reads a strict, versioned JSON file. Names, SSNs, addresses, and account numbers are rejected.
  • New files are created with mode 0600 on macOS and Linux.
irs-taxpayer-mcp template --output facts.json
irs-taxpayer-mcp validate --facts facts.json
irs-taxpayer-mcp plan --facts facts.json --json

MCP server, 45 tools

For your AI assistant

  • Works with Claude, Kiro, Cursor, and other MCP clients.
  • The engine still calculates locally and stores nothing.
  • Plans report modelInvoked: true, because your assistant may have seen the facts.
  • Ask in plain language and get the same deterministic numbers.
{
  "mcpServers": {
    "irs-taxpayer": {
      "command": "npx",
      "args": ["-y", "irs-taxpayer-mcp"]
    }
  }
}

Be precise about privacy. With a cloud-hosted MCP client, your prompts and tool arguments go to that client's model provider. If that matters, use the direct command line.

Built to say "no"

A tax tool earns trust by what it refuses to do.

It fails closed

An unsupported tax year, state, or missing required fact returns an error. It never falls back to a rough top-rate guess.

It is not filing software

It does not prepare, sign, or transmit a return, and it does not model every form, schedule, or election.

It shows its work

Every plan lists its assumptions, the official IRS and SSA sources it used, and a calculation trace. A model never does the arithmetic.

Questions

Which years and states are covered?

Federal estimates cover TY2024 through TY2026 for the inputs each tool exposes. Reference data covers all 50 states and DC, but numeric state estimates need an exact tax-year profile. The README lists the supported state-year paths.

Do I need an IRS login or my SSN?

No. The tool needs no account and no identifying information. The facts file format rejects names, SSNs, addresses, employer IDs, and account numbers.

Can I trust the numbers?

Treat them as planning estimates. Tests cite IRS revenue procedures and Internal Revenue Code sections, and the same inputs always give the same answer. If you find a wrong number, report it with a rounded or synthetic example and no personal details.

Does it replace a tax professional?

No. It supports planning decisions and does not give tax, legal, or financial advice. Check important decisions with a qualified professional.

Run it on your own numbers.

Install takes one command. In direct mode your tax facts stay on your machine. Found a wrong number, or want a case supported? Tell us.
